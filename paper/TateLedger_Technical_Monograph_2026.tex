\begin{abstract}
Standalone reference ledger (`docs/STATEMENT.md`, `docs/KNOWN\_CASES.md`, `docs/IMPLICATIONS.md`, `docs/HODGE\_COMPARISON.md`, `docs/NOT\_THIS\_HOST.md`) cataloging the exact scope of the Tate Conjecture, proven cases (Faltings for divisors on abelian varieties over number fields,Zarhin over function fields, Charles-Madapusi Pera-Maulik for K3 surfaces), implications for BSD/Mordell-Weil ranks, and structural differences from the complex Hodge Conjecture.
\end{abstract}

\section{Scope, Scientific Honesty, and Non-Claim Boundary}

\section{Technical Overview \& Repository Specification}

Public ledger of the Tate conjecture.

This repository is **not** a proof of Tate.

This repository is **not** a proof of Hodge.

It names the sentence, records implications, and points at prior theorems.

Lean skeleton of the same sentence: [BenFrohman/TateConjecture](https://github.com/BenFrohman/TateConjecture)

Complex Hodge ledger: [BenFrohman/HODGE](https://github.com/BenFrohman/HODGE)

Let `X` be smooth projective over a finite field `F\_q`.

After a Tate twist, the cycle class map lands in Galois invariants:

cl : CH\textasciicircum{}i(X)\_Q \textbackslash\{\}otimes Q\_\textbackslash\{\}ell  \textbackslash\{\}to  H\textasciicircum{}\{2i\}\_et(X\_\{bar F\_q\}, Q\_\textbackslash\{\}ell(i))\textasciicircum{}\{Gal\}

Tate: that map is surjective.

The numerical shadow is that geometric Frobenius on `H\textasciicircum{}\{2i\}` has eigenvalue `q\textasciicircum{}i` on the Tate classes. For fourfolds and `i = 2` that shadow is `q\textasciicircum{}2` on `H\textasciicircum{}4`. Weil already forces `|\textbackslash\{\}alpha| = q\textasciicircum{}2` on `H\textasciicircum{}4`. The root `q\textasciicircum{}2` is a condition on a class, not a surface.

Writing `cl(z) = \textbackslash\{\}gamma` is the hard arrow. This repository does not write those cycles for an unspecified `X`.
