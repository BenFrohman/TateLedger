Author: Benjamin Stanley Frohman
Copyright (c) 2026 Benjamin Stanley Frohman
License: Apache-2.0

This is a mathematics ledger. There is no production service and no user data.
The threat model is mathematical integrity.

## Report

- A file that claims Tate is proved when it is only named.
- A file that treats a Frobenius eigenvalue as a constructed cycle.
- A file that imports a complex Hodge class as a Galois invariant without a named reduction of a named variety.
- Accidental credentials, tokens, or private keys in a commit.
- A license or authorship header that drops the copyright line.

## Do not report as security issues

- That Tate is still open. That is the point of the ledger.
- That Hodge is still open. See https://github.com/BenFrohman/HODGE

## How to report

Open a GitHub issue titled `integrity:` or contact [@BenFrohman](https://github.com/BenFrohman).
Do not file a fake Clay close.
