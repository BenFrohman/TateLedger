# Hodge and Tate side by side

Author: Benjamin Stanley Frohman
Copyright (c) 2026 Benjamin Stanley Frohman
License: Apache-2.0

| | Hodge | Tate |
|---|---|---|
| Ground | C | finite field |
| Allowed classes | type (i,i) | Galois invariants after twist (i) |
| Divisors | Lefschetz (1,1), theorem | open in general; known for abelian varieties and K3s |
| First hard geometric case | (2,2) on a fourfold | same dimension, etale H^4, eigenvalue q^2 |
| On the locked complex host V(F) | rho >= 3, dim im(cl) >= 3, Z uncomputed | not set up: no named reduction, no named Tate class |
| What closes it | surfaces Z_i and a_i with gamma = sum a_i [Z_i] | cycles over F_q whose classes span the Galois invariants |

Two conjectures. One missing object: the cycle.
Tate does not inhabit Field 3 of a Hodge disproof.
Hodge on V(F) does not discharge Tate.
